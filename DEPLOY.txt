================================================================================
  CARA DEPLOY PORTFOLIO INI (PortoFauzan)
================================================================================

Project ini adalah website STATIS (index.html + css + js + images).
Tidak perlu server khusus — cukup hosting file statis.

Repo GitHub kamu:
  https://github.com/komfauzan-alt/portfolio-fauzan

Setelah online, alamat biasanya:
  https://komfauzan-alt.github.io/portfolio-fauzan/


================================================================================
  CARA 1 — GITHUB PAGES (DISARANKAN, GRATIS)
================================================================================

Langkah A — Push kode terbaru ke GitHub
---------------------------------------
Buka terminal di folder project (c:\portofolio), lalu:

  git add .
  git commit -m "Update portfolio"
  git push origin main

(Kalau commit sudah ada tapi belum push, cukup: git push origin main)


Langkah B — Aktifkan GitHub Pages
---------------------------------
1. Buka: https://github.com/komfauzan-alt/portfolio-fauzan
2. Klik tab **Settings**
3. Menu kiri: **Pages**
4. Di **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Klik **Save**

Tunggu 1–3 menit. Refresh halaman Pages — akan muncul link hijau:
  "Your site is live at https://komfauzan-alt.github.io/portfolio-fauzan/"


Langkah C — Cek hasil
---------------------
- Buka link di atas di browser
- Kalau gambar/tombol tidak jalan, hard refresh: Ctrl + F5


Setiap kali update portfolio:
  git add .
  git commit -m "Deskripsi perubahan"
  git push origin main
  (GitHub Pages otomatis update beberapa menit kemudian)


================================================================================
  CARA 2 — NETLIFY (GRATIS, MUDAH)
================================================================================

Opsi A — Drag & drop (tanpa Git)
1. Buka https://app.netlify.com/drop
2. Login / daftar
3. Tarik SELURUH folder portofolio (yang ada index.html) ke area drop
4. Netlify kasih URL random, misalnya: https://nama-acak.netlify.app

Opsi B — Connect GitHub
1. https://app.netlify.com → Add new site → Import an existing project
2. Pilih GitHub → repo portfolio-fauzan
3. Build settings:
   - Build command: (kosongkan)
   - Publish directory: /  atau .
4. Deploy


================================================================================
  CARA 3 — VERCEL (GRATIS)
================================================================================

1. Buka https://vercel.com → Sign up (bisa pakai GitHub)
2. Add New Project → Import repo portfolio-fauzan
3. Framework Preset: **Other**
4. Root Directory: . (default)
5. Build Command: kosong
6. Output Directory: kosong (root)
7. Deploy

URL contoh: https://portfolio-fauzan.vercel.app


================================================================================
  HAL YANG PERLU DIPERHATIKAN
================================================================================

1. Form Contact (Formspree)
   - Form di index.html pakai Formspree — tetap jalan setelah deploy
   - Pastikan email Formspree sudah diverifikasi

2. File besar
   - GitHub: file per file max ~100 MB (repo total disarankan < 1 GB)
   - Zip di folder arduino/ ikut ter-upload kalau di-commit

3. Nama file ada spasi (misalnya "schema hardware.jpeg")
   - Tetap jalan di GitHub Pages, tapi hindari spasi untuk file baru

4. Custom domain (opsional)
   - GitHub Pages / Netlify / Vercel semua bisa pakai domain sendiri
   - Setting ada di dashboard masing-masing (Settings → Domains)


================================================================================
  TROUBLESHOOTING
================================================================================

- Halaman 404
  → Pastikan index.html ada di ROOT repo (bukan di subfolder)
  → GitHub Pages: branch main, folder / (root)

- CSS/JS tidak load
  → Path harus relatif: css/style.css, js/script.js (sudah benar di project ini)
  → Jangan buka file pakai file:// — harus lewat https://

- Perubahan tidak muncul
  → Tunggu 2–5 menit setelah push
  → Ctrl + F5 atau buka Incognito

- Push ditolak
  → Login GitHub: git config (jangan ubah global tanpa perlu)
  → Pakai Personal Access Token jika diminta password
